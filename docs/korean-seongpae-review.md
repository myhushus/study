## 해석과 번역의 유의점

1. 성패가 천운에 달렸다는 인식과 사람이 의로움을 따라야 한다는 요구를 구별한다. 전자를 사람의 선택 책임을 없애는 체념으로, 후자를 성공의 보장으로 바꾸지 않는다.
2. `雖然反夙莫`는 양보·가정으로 읽는다. 아침과 저녁을 뒤바꾸는 상황을 화자가 실제로 경험했다는 사건으로 확정하지 않는다. `詎可倒裳衣`는 옷의 질서로 도리를 빗댄 설의이며, 물리적 실행 난도를 비교하는 말이 아니다.
3. 경(經)은 지켜야 할 원칙, 권(權)은 상황에 맞춘 판단·대응이다. 권을 사익·부도덕의 동의어로 풀이하거나 어떠한 상황 판단도 불필요하다고 단정하지 않는다. 작품은 권의 오용 위험과 경을 지켜야 할 당위를 대비한다.
4. 어진 이조차 오류를 범할 수 있다는 가능성과 누구도 경을 어겨서는 안 된다는 규범은 실제 위반 사건의 보고가 아니다. 청자가 이치에 밝다는 표현도 개별 판단의 무오류를 보증하지 않는다.
5. `造次愼衡機`는 다급할 때에도 판단을 신중히 하라는 권고이다. 판단을 모두 중단하라는 말이나, 과거의 판단이 옳았다고 인증하는 말로 바꾸지 않는다.
6. 비교 작품에서는 공적을 깎는 외부의 평가와 이름이 널리 알려진 사실, 태평의 기대와 현재 난리, 근심의 해소라는 조건과 귀거래사의 장래 지향을 각각 구별한다.
