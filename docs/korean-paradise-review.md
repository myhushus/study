# 한용운 〈낙원은 가시덤불에서〉 제작·검토 기록

확인일: 2026-09-18. 기준 커밋: `0e3c31a831b5da8e39091e3ac02b93a79b3f1c43`.

## 원문·이용 상태·EBS 수록

- [EBSi 2027 수능특강 최서희 문학 36강](https://www.ebsi.co.kr/ebs/lms/player/retrieveLmsPlayerHtml5.ebs?lecGbn=V500&lessonId=LS100030081294&sbjtId=S20250000854&sbjtapplyId=)의 갈래 복합 06 목차에서 한용운 〈낙원은 가시덤불에서〉 수록을 확인했다. EBS 문제나 해설, 함께 수록된 저작권 보호 작품은 복제하지 않았다.
- [위키문헌 『님의 침묵』](https://ko.wikisource.org/wiki/님의_침묵)의 저작권 만료 표기를 확인하고, [「樂園은가시덤풀에서」 원문 전사](https://ko.wikisource.org/wiki/님의_침묵/낙원은_가시덤풀에서)의 옛 표기 본문을 대조했다. 확인한 판은 `oldid=430707`이다. 별도의 유사 제목 문서가 아니라 시집 목차에서 연결된 이 문서를 사용했다.
- 옛 철자·한자·띄어쓰기·문장부호 일부를 현대 표기로 정리했다. 제목의 ‘가시덤풀’을 ‘가시덤불’로, ‘丈六金身’을 ‘장륙금신’으로 적었다. 3연의 구성을 유지하고 꽃방울·쇠잔·소조 등의 어휘를 남겼다. 특정 EBS 판본과 글자 단위로 동일하다고 주장하지 않는다. 편집된 현대 시집의 해설은 이용하지 않았다.
- 장륙금신의 어휘는 [한국학중앙연구원 HeritageWiki의 고창 선운사 영산전 설명](https://dh.aks.ac.kr/~heritage/wiki/index.php/고창_선운사_영산전)을 참고했다. 문항에서는 ‘부처의 몸을 이르는 말’이라는 뜻을 제공하므로 별도의 불교 지식을 요구하지 않는다.
- 비교 작품은 기존 `lessons/spring.js`의 이상화 〈빼앗긴 들에도 봄은 오는가〉 본문을 그대로 사용했다. 이 두 작품이 EBS에서 한 세트로 묶였다는 뜻은 아니다.

## 해석·문항 범위

같은 눈에 죽음과 향기의 관계가 함께 부여된다는 점, 사라진 녹음이 현재의 단풍에 연결된다는 점을 읽는다. 자연의 변화를 과학적 인과 법칙으로 주장하지 않는다. 한쪽 의미만 남기거나, ‘기억에만’이라는 말을 관계의 완전한 단절로 확대하지 않는다.

‘일경초가 장륙금신이 되고 장륙금신이 일경초가 된다’는 양방향 구조를 읽되, 특정 교리의 명칭을 외워야 정답을 고르게 하지 않는다. 마지막의 ‘위하여’는 목적이며 낙원 건설의 완료가 아니다. 고통에 새 의미를 부여하는 태도를 실제 고통의 부재와 혼동하지 않는다. 모든 현실의 고통이 반드시 행복을 보장한다는 일반 명제로 확대하지 않는다.

이해 유도 8문항 → 핵심 정리 → 일반 3문항 → 수능형 연습 3문항 → 기출 대조 실전 5문항. 총 19문항. 실전 정답은 ⑤·②·④·③·①이며 각 선택지에 개별 판단 근거를 제공한다. 이해 단계는 오답에 재독 힌트를 제공하고, 실전은 전체 제출 후 채점한다.
