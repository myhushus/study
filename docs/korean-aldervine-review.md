- 새 작품의 콘텐츠·파일 보존·링크·캐시·Chromium DOM 검사 **555개 세부 단언**이 통과했다. 이 수에는 변경 대상 외 기존 Pages 산출물 **187개 파일의 바이트 보존** 확인이 포함되며, 555개의 독립 사용자 시나리오라는 뜻은 아니다.

- 재풀이·초기화 취소/확인, 이전 단계 및 다른 저장 키 보존, 손상 JSON·콘텐츠 버전 불일치·범위 밖 답안·저장 불가 안내, 직접 실전 진입, 중복 초기화 방지를 검사했다.
- 별도 회귀 실행에서 공통 렌더러를 쓰는 기존 **27작품**의 로드·29작품 메뉴·실전 만점 채점이 통과했다. 회귀 실행의 487개 단언에는 앞의 정적 검사가 중복되므로 두 수를 합산하지 않는다. 독립 렌더러 〈길〉과 수학의 직접 조작은 수행하지 않고 파일 보존으로 확인했다.
- 320/360/780/1100px 초기 화면 및 실전 5문항의 채점 전·후 가로 넘침 없음. 320px 본문·선택지·보기·참고 글자 두 배 확대도 통과했다. 360px 학습 화면과 실전 4번 이미지를 직접 열어 검수했다. 미처리 JavaScript 오류 없음.
- localhost HTTP 탐색이 `ERR_BLOCKED_BY_ADMINISTRATOR`로 거부되어 `set_content`와 location/localStorage/navigator 테스트 대역을 사용했다. 복원은 메모리 저장 대역의 직렬화·재주입 검사이며 실제 브라우저 영속 저장소 검증은 아니다. 실제 배포 도메인의 전체 사용자 조작과 서비스 워커 네트워크 수명 주기도 검증하지 않았다.
- 최초 전체 검사에서 진행 상태 기대 문자열에 ‘응답’이 빠져 중단되었다. 테스트 기대값만 수정하고 새 작품 검사와 전체 회귀 검사를 통과했다. 게시 코드는 변경하지 않았다.
- 테스트 코드·대역·검토용 JSON·스크린샷은 게시하지 않는다.
