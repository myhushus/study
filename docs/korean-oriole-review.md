## 해석의 범위

- 가족 호칭을 기준으로 화자를 작은아들의 아버지·손자의 할아버지로 읽고 지어미는 화자의 아내로 풀이한다. 화자와 실제 작가의 생애를 동일시하지 않는다.
- 꾀꼬리 소리는 낮잠에서 깨어나는 계기이다. 새에 대한 원망이나 꿈속 재회, 특정 계절을 본문에 없는 사실로 덧붙이지 않는다.
- 며느리의 베 짜기, 아내의 술 거르기는 노동이다. 평온한 분위기가 모두의 무위·무노동이나 각 인물의 직접적인 만족 발언을 뜻하지는 않는다.
- 중장의 나열은 세 활동의 완료 순서를 확정하지 않는다. 마침은 앞의 활동이 모두 끝나서 술 거르기가 시작되었다는 인과·선후의 근거가 아니다.
- 맛보라는 말의 주체는 아내, 상대는 화자이다. 권유 뒤 실제 음주·취함·대답은 제시되지 않는다.
- 비교 작품에서는 공적 성취 뒤의 은거, 소박한 거처와 물질적 여유, 노복의 노동과 화자의 만족을 구별한다. 노복의 속마음이나 특정 시대의 실제 태평함은 추론하지 않는다.
