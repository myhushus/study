# 이중경 〈어부별곡〉 제작·검토 기록

확인일: 2026-10-01. 기준 main: `614a66182d17c2ccdc37d9dc181712f89c4a481d`.

## 수록 및 원문 확인 범위

- 2027 EBS 수능특강 문학 적용 학습 고전 시가 09 수록은 [써머썬의 해당 단원 목록](https://contents.premium.naver.com/summersuninst/summersun/contents/260419064737159ib)과 [김은광 수능국어의 수록 위치·범위 자료](https://ekkorean.com/learn/classic-poetry-09)를 교차 확인했다. 자료들은 〈몽금포 타령〉과의 묶음 및 71~73쪽, 제2·3·4·6수 발췌를 제시한다.
- EBSi 최서희 09강과 한병훈 10강의 강의 제목은 검색·페이지로 확인했지만, 작품명이 나타나는 상세 인덱스와 교재 지면은 직접 확인하지 못했다. 따라서 공식 지면을 직접 확인했다고 주장하지 않으며, learner 화면에 쪽수를 확정적으로 덧붙이지 않는다.
- 본문은 [장인진의 오대어부가 연구 강의 전재 자료](https://hjgb3911.tistory.com/522)의 「어부별곡 전3장·후3장」 옛말 전사와 [2016년 11월 고1 전국연합학력평가 문제지](https://t1.daumcdn.net/cfile/tistory/234D0B48584643291D)의 12쪽 지문을 대조했다. 후자는 텍스트를 확인했으며 웹의 페이지 이미지 요청은 실패했다. 원전 영인본 판독은 아니다.
- 수헌 이중경의 생몰년 1599~1678은 [한국민족문화대백과사전 오산지](https://encykorea.aks.ac.kr/Article/E0066644)로 확인했다. 다른 생몰년의 동명이인 이중경과 혼동하지 않는다.
- 저작권 만료 원작을 한자 병기·옛 철자·일부 어휘를 정리한 여섯 수로 제공한다. 전3장을 제1~3수, 후3장을 제4~6수로 표시한다. 제1수의 탄식·망극한, 제5수의 차생·일일·아희 및 마지막 구는 학습용으로 풀었다. 제5수 ‘윗는 줄’은 학력평가가 제시한 나이 관련 의미를 따랐으며, 원전의 철자를 그대로 재현한다고 하지 않는다. 교재의 표기·발췌 범위와 다르다.
- 외부의 문제·해설을 전재하지 않는다. 2016 고1 학력평가는 원문 뜻 대조 자료이지 수능 난도 기준이 아니다.

## 비교 작품과 해석 원칙

비교는 기존 이순신 〈진중음〉 학습 자료의 EBS 수록 제3수이다. live 파일 `lessons/jinjungeum.js`의 blob `aa425315b87e17baaaa87c58b0eb588ba01c3af6`를 확인했고 네 묶음의 한국어 본문을 정확히 사용했다. 그 자료의 공식 수록 확인 근거는 PR #16과 해당 lesson의 source 기록을 따른다. 이번에 EBS 비교 지면을 재확인한 것은 아니며 실제 EBS의 작품 묶음을 재현하지 않는다.

어부별곡의 명리에 대한 자기 반성을 진중음의 타인에 의한 평가와 혼동하지 않는다. 자연에서의 만족을 나라에 대한 무관심이나 정치 현실이 해결되었다는 사건으로 확대하지 않는다. 노년의 몸과 젊은 마음, 현재의 자연 생활과 조건부 전원 귀환, 대구·병렬과 의미상의 대립을 구별한다. 제1수의 슬픔은 본문에 근거해 읽게 하며, 별도 맥락 없이 특정 사별 사건을 정답으로 요구하지 않는다.
