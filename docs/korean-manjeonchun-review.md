## 해석과 출제 범위

양보·조건·청유·의문에 따라 시구가 말하는 사실과 소망의 범위를 구별한다. 극한의 조건도 감수하겠다는 말의 목적을 죽음으로 바꾸지 않는다. 잠들지 못함을 기꺼이 깨어 있는 실천으로 바꾸지 않는다. 도화의 시름없음은 화자의 시름없음이 아니다.

4연은 물오리의 거처를 묻는 말과 조건부 응답의 차이를 먼저 읽는다. 인간관계에 대응시키는 문항은 그 해석 관점을 〈보기〉에 명시한다. 인물의 성별이나 하나의 우의적 해석을 작품의 확정된 사실로 전제하지 않는다. 소가 얼 경우를 이미 얼어 이동한 사건으로 바꾸지 않는다.

여러 장면과 목소리를 실제 사건의 연대기로 환원하지 않는 읽기를 〈보기〉로 제공한다. 결말이 사랑의 지향을 모으는 것과 앞의 갈등이 현실에서 해결되는 것은 구별한다. 5연의 친밀한 형상화를 합의·재회 완료의 증거로, 마지막의 청을 상대가 이미 응답했다는 보고로 바꾸지 않는다.

## 학습 구성과 실제 기출 대조

이해 유도 8문항 → 핵심 정리 → 일반 3문항 → 수능형 연습 3문항 → 실전 5문항. 총 19문항. 문제와 해설은 새로 작성했다. 실전은 전체 제출 후 채점하고 다섯 문항의 모든 선택지에 개별 근거를 제시한다.

[2026학년도 실제 수능 국어 짝수형 문제지](https://wdown.ebsi.co.kr/W61001/01exam/20251113/go3/korA_2_mun_W767CHHO.pdf)의 고전 시가 31~34번과 관련 지문, 〈보기〉, 선택지를 검토했다. 문제지의 11~12쪽 페이지 이미지도 확인했다. 2025 문제지 이미지 요청은 실패했으므로 이번 문항의 직접 대조 기록은 2026학년도 문항으로 한정한다.

| 새 실전 | 대조 문항 | 적용한 판단 구조 |
|---|---|---|
| 1 | 2026학년도 32번 | 시구의 상황·평가를 연결할 때 심리 상태를 의도된 행위로, 이를 다시 요청의 실천 수단으로 바꾸지 않는다. |
| 2 | 2026학년도 33번 | 발화의 대상과 행위의 방향·조건을 함께 보고, 물음이 요구하는 것과 응답의 판단 기준을 구별한다. |
| 3 | 2026학년도 31번 | 표현 형식과 정서적 효과를 따로 점검하고 작품마다 자연물과 화자의 관계를 판단한다. |
| 4 | 2026학년도 34번 | 〈보기〉를 적용할 때 비교라는 맞는 설명 뒤에 응답 실패와 보상이라는 미제시 사건·인과가 붙었는지 확인한다. |
| 5 | 2026학년도 34번 | 장면의 형상화·정서의 통일과 현실 사건의 완료·상대의 합의를 구별한다. |

실전 정답: ③, ①, ⑤, ②, ④. 선택지별 해설 25개. 기출 문구나 선택지를 복제하지 않았으며 실제 정답률·변별도·동일 난도를 실증 검증한 것은 아니다. 제작 및 기출 대조 정보는 이 문서와 데이터에만 남기고 풀이 화면에는 표시하지 않는다.

## 검증

- 신규 데이터·작품 메뉴·서비스 워커의 `node --check` 통과.
- Chromium 격리 DOM 및 콘텐츠·파일 보존 검사 112개 통과. 전체 학습 단계, 오답 재독 힌트와 명시적 해설 확인, 미응답 제출 차단, 제출 전 답 비공개, 답안 변경·복원, 5/5 및 0/5 채점, 25개 선택지 근거의 데이터 일치, 초기화 확인 및 범위 분리, 기존 저장 키 보존, 손상·버전 불일치·범위 밖·차단 저장 복구, 중복 초기화 방지, 기존 공유 렌더러 열 작품의 채점·연/수/구간 표시 회귀를 포함한다.
- 320/360/780/1100px의 최초 화면과 모든 실전 문항에서 가로 넘침이 없었다. 360px 최초 화면과 실전 보기·선택지 화면을 이미지로 확인했다. 미처리 JavaScript 오류는 없었다.
- 파일 URL 탐색은 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단되었다. 원본 공유 렌더러에 location/localStorage/navigator 어댑터를 주입한 격리 DOM 검사이며 실제 배포 사이트의 전체 조작이나 서비스 워커의 네트워크 수명 주기를 검증한 것은 아니다.
- 해시 대조로 기존 파일 중 작품 메뉴·서비스 워커만 변경되었음을 확인했다. 비교 본문은 기존 〈만흥〉 데이터와 일치하고 작품 메뉴의 모든 경로가 존재한다.
