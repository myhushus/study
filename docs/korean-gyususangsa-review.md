기능 검사는 19문항 전 단계, 이해 오답 힌트·재시도·명시적 해설, 미응답 차단, 제출 전 정답 비공개, 답 변경, 직렬화된 답·결과의 재주입 복원, 5/5·0/5 채점, 25개 근거 문자열 일치, 제출 후 답 잠금, 재풀이·초기화의 취소/확인, 다른 시·수학의 예시 기록 보존을 포함한다. 손상 JSON·구버전·범위 밖 답안·저장 거부·실전 해시 진입·중복 초기화·키보드 라디오 선택도 확인했다.

기존 공통 렌더러 작품 36편은 로드, 38편 메뉴, 실전 만점 채점을 검사했다. 모든 기존 학습 단계의 전수 회귀를 의미하지 않는다. 독립 렌더러의 〈길〉과 수학은 파일 보존으로 확인했으며 전체 직접 조작을 다시 검사하지 않았다.

320×640, 360×800, 600×500, 780×500, 781×600, 1100×800에서 초기 화면과 비교 작품을 펼친 실전 다섯 문항의 제출 전·후 가로 넘침이 없었다. 추가로 320px에서 읽기·문항·선택지·보기·해설을 32px로 확대해 제출 후 다섯 문항을 확인했다. 모든 운영체제 최대 시스템 글자 크기를 검사했다는 뜻은 아니다. 360px 실전 4번 학습 카드와 1100px 실전 3번 학습 영역 스크린샷을 열어 시각 검수했다.

localhost HTTP 탐색은 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단되어 실제 게시용 소스와 CSS를 Chromium `set_content`에서 실행했다. location·localStorage·navigator는 범위가 제한된 테스트 대역으로 제공했다. 저장 복원은 메모리 대역의 직렬화·재주입 검사이며 실제 영속 저장소 검증이 아니다. 대부분의 선택·버튼 조작은 DOM 이벤트로 실행했고 라디오 키보드 조작을 별도로 확인했다. 첫 포인터 중심 실행은 실행 시간 제한으로 중단되었고, 테스트 조작 방식을 바꾼 뒤 전체 검사를 다시 통과했다. 이를 위해 제품 코드를 바꾸지 않았다.
