## 해석과 문항의 범위

풍경 속 비유의 주체를 산굽이·정자·물·기러기·산·구름으로 구분한다. 구름의 왕래를 화자의 실제 이동 경로로 옮기지 않는다. 흰 모래의 눈 비유와 겨울의 실제 빙설을 구분한다.

‘겨를 없음’은 누리고 싶은 활동이 많다는 문맥에서 읽는다. 이 활동의 분주함과 취흥 속 심리적 한가함은 양립할 수 있으며, 술 이전의 생활을 무조건 괴로움으로 만들지 않는다. 속세를 떠나는 것과 모든 인간관계를 끊는 것은 다르므로 벗의 교유와 모순되게 해석하지 않는다.

신선의 이미지는 벗·술·음악과 함께하는 현재의 자기 상태에 연결한다. 이태백이 돌아오는 상정을 실제 만남으로 읽지 않는다. 호탕정회를 높이는 주체는 화자이고, ‘역군은’은 이 생활을 가능하게 한 은혜에 대한 감사이다. 임금이 화자의 미적 우월성을 승인한 것으로 바꾸거나, 감사가 자기 긍정을 철회한 것으로 읽지 않는다.

## 구성과 기출 대조

이해 유도 8 → 핵심 정리 → 일반 3 → 수능형 연습 3 → 실전 5. 총 19문항. 새 실전은 전체 제출 이후 정답·해설·25개 선택지별 판단 근거를 공개한다. 이해 단계는 오답 시 재독 힌트를 먼저 제공한다.

[2026학년도 실제 수능 국어 짝수형 문제지](https://wdown.ebsi.co.kr/W61001/01exam/20251113/go3/korA_2_mun_W767CHHO.pdf)의 고전 시가 31~34번 지문·보기·선택지를 읽고, 인쇄 11~12쪽(파일 페이지 10~11)의 이미지를 직접 대조했다. 이번 작업에서 2025학년도 문제지까지 대조했다고 주장하지 않는다. 원래 문항을 복사하지 않고 독해 판단 구조를 참고했다.

| 새 실전 | 대조 기출 | 적용한 판단 |
|---|---|---|
| 1 | 2026학년도 32번 | 지시 대상과 행위 주체를 추적하고 자연물의 이동을 관찰자의 이동 경로로 바꾸지 않기 |
| 2 | 2026학년도 32번 | 문맥별 상태와 원인을 연결하고 근거 없는 인과·전환을 배제하기 |
| 3 | 2026학년도 31번 | 사용된 표현 방식과 그 표현에 붙인 정서·효과를 따로 검토하기 |
| 4 | 2026학년도 31번 | 두 작품의 공통 표현을 찾되 계절·대상까지 같다고 확대하지 않기 |
| 5 | 2026학년도 34번 | 보기의 관점으로 자기 평가의 주체와 삶의 근원을 구별하기 |

실전 정답: ④, ①, ⑤, ③, ②. 각 선택지의 잘못된 연결 또는 타당한 근거를 따로 작성했다. 수험생 표본의 정답률·변별도는 측정하지 않았으므로, 수능과 같은 실측 난도라고 단정하지 않는다. 제작·대조 기록은 데이터와 이 문서에만 남기며, 풀이 화면에 부가 소개·진행·제작·난도 설명을 넣지 않았다.
