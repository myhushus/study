### 표기 원칙

위키문헌의 ‘그 땅에도’를 유지한다. ‘그때에도’를 쓰는 판본과 다르며 특정 EBS 판본을 그대로 전사한 자료가 아니다. 이 차이를 정답 판단의 근거로 삼지 않는다. ‘나리쟎는→내리잖는’, ‘날라오길→날아오길’과 일부 띄어쓰기·한자 병기를 정리했다. ‘쉬임’은 남겼다. 12행은 공간 전개에 따라 4행씩 묶어 표시했으며, 이 구획이 원전의 지면상 연 구분과 같다고 주장하지 않는다. 표기 원칙과 이용 정보는 접힌 출처 영역에 남긴다.

비교 작품은 기존 lessons/spring.js의 이상화 〈빼앗긴 들에도 봄은 오는가〉 11연 전문을 바이트 변환 없이 줄바꿈으로 연결했다. 비교용 선택이며 EBS의 실제 짝 작품이라는 뜻이 아니다.

## 학습 구성

이해 유도 8문항 → 핵심 정리 → 일반 3문항 → 수능형 연습 3문항 → 기출 대조 실전 5문항. 총 19문항. 해설은 새로 작성했다.

이해 유도에서는 조건과 개화의 대비, 의문형의 실제 의미, 목숨과 꽃의 관계, 움직임의 주체, 기다림과 완료의 차이, 약속, 직유, 현재의 호명을 차례로 읽는다. 오답에는 재독 힌트를 먼저 제시하고, 다시 답하거나 명시적으로 해설을 확인할 수 있다.

실전은 5지선다이며 전체 제출 후 채점한다. 25개 선택지의 판단 근거를 제공한다. 부가 소개·난도 안내·제작 설명은 학습 화면에 렌더링하지 않는다. 기출 대조 메타데이터는 검토용으로만 보존한다.

### 정답 유일성 검토

1번은 꽃과 ‘내 목숨’, 보리밭과 ‘내 머리’라는 두 작품의 근거를 동시에 요구한다. 2번은 맹아리·제비·회상의 무리·화자를 각각 술어에 대응시킨다. 3번의 오답은 실제 표현 기법에 없는 실현·대답·체념·기억 삭제·문제 해결을 덧붙인다. 4번의 오답은 미래의 소망이 있다는 사실을 현재의 교감이 불가능하다는 필요조건으로 바꾼다. 5번은 상징의 전개와 실제 사건의 연대기를 구별한다.

‘회상의 무리들’과 ‘너’의 구체적 신원·집단을 하나로 단정하지 않는다. ‘꽃성’을 지향하는 세계로 읽는 문제에는 보기의 관점을 제공한다. 현재형의 호명이 실제 독립·귀환·자연의 응답이 완료되었다는 역사적 보고라고 해석하지 않는다.

난도는 기출의 판단 구조를 기준으로 설계한 것이며, 수험생 정답률·변별도와 같은 경험적 난도가 검증된 것은 아니다. 특정 등급 또는 실제 수능과 동일한 난도를 보장하지 않는다.

## 구현과 회귀 검사

- 새 페이지: korean-flower.html. 새 데이터: lessons/flower.js.
- poetry-nav.js에 세 번째 작품을 추가했다.
- poetry-lesson.js는 국어 버튼의 목적지를 현재 작품 경로로 정하는 한 표현만 수정했다. 기존 봄 작품의 자기 경로는 그대로다.
- 서비스 워커는 v13→v14와 새 HTML/데이터의 CORE 등록만 변경했다. 요청 처리 로직은 그대로다.
- 저장 키: study-poetry-flower-v1, contentId: flower-20260918-v1. 이전 작품·수학 저장 키는 건드리지 않는다.
- 새 데이터·수정 JS의 node --check 통과.
- Chromium 격리 DOM 및 파일 보존 검사 71개 통과: 8→정리→3→3→5 진행, 오답 힌트·재시도·해설 확인, 제출 전 정답 비공개, 미응답 제출 차단, 답안 수정·복원, 전체 정답/오답 채점, 25개 선택지 해설, 초기화 확인, 다른 기록 유지, 손상·차단 저장 복구, 중복 실행 방지, 기존 두 작품 로드, 320/360/780/1100px 가로 넘침 없음, 미처리 스크립트 오류 없음.
- 테스트는 원본 스크립트에 location/localStorage/navigator/history 어댑터를 주입한 격리 DOM 실행이다. 로컬 HTTP 탐색은 ERR_BLOCKED_BY_ADMINISTRATOR로 차단되었다. 실제 배포 사이트의 네트워크 E2E 검사를 했다는 뜻이 아니다.
- 기존 작품 본문·문항 데이터, 기존 수학 파일 및 기타 비대상 파일은 바이트 단위로 동일하다.
