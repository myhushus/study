# 이육사 〈꽃〉 학습 제작·검토 기록

확인일: 2026-09-18. 기준 커밋: c15c90ee2f30ec4a96113e17f0c18d83d51e0d20.

## 원문과 EBS 수록

- [EBSi 2027 수능특강 한병훈 문학 03강](https://www.ebsi.co.kr/ebs/lms/player/retrieveLmsPlayerHtml5.ebs?lecGbn=V500&lessonId=LS100030078574&sbjtId=S20250000855&sbjtapplyId=)의 90~92쪽 적용 학습 04에서 이육사 〈꽃〉 수록을 확인했다. 교재의 문제·해설은 복제하지 않았다.
- [위키문헌 〈꽃〉](https://ko.wikisource.org/wiki/꽃)의 공개 원문 전사를 기준으로 3연 12행을 구성했다. 원문에 표시된 ‘그 땅에도’, ‘맹아리’, ‘못할’을 사용하고 옛 철자·띄어쓰기·한자 병기를 일부 정리했다. 특정 EBS 판본과 글자 단위로 동일하다는 뜻이 아니다. 교재와의 표기 차이는 접힌 출처에 안내한다.
- [한국저작권위원회 공유마당 작가 정보](https://gongu.copyright.or.kr/gongu/authr/authr/viewWrtrPage.do?authrSn=2148&menuNo=200186)에서 이육사의 1944년 사망을 확인했다. 저작권 만료 원작을 사용한다. 이 링크는 개별 〈꽃〉 원문 다운로드 페이지가 아니라 작가 정보이며, 사이트에서도 그에 맞게 표시했다.
- 비교 작품은 기존 `lessons/spring.js`의 이상화 〈빼앗긴 들에도 봄은 오는가〉 본문을 그대로 사용했다. 이번 비교 조합은 자체 제작이며 EBS 교재의 조합이라고 주장하지 않는다.

## 문항 구성과 검토

이해 유도 8문항 → 핵심 정리 → 일반 3문항 → 수능형 연습 3문항 → 기출 대조 실전 5문항. 총 19문항.

이해 단계는 환경의 가혹함, ‘오히려’와 설의의 의미, 눈 속의 생명 활동, 기다림과 도착의 구별, 부정이 걸리는 동사, 움직임의 이미지, 부르는 주체, 전체 주제를 순차적으로 연결한다. 오답이면 재독 힌트를 제공하고 재시도 또는 명시적 해설 확인으로 진행한다.

실전은 문항 사이 이동과 답안 수정을 허용하고 전체 제출 후에만 채점과 25개 선택지별 근거를 표시한다. ‘너’의 상징을 특정 역사적 인물로 단정하는 해석을 정답 조건으로 삼지 않았다. 본문에 없는 도착·응답·여행·인과의 추가를 구분하게 했다.

아래 문제지의 텍스트와 8~9쪽 페이지 이미지를 이번 작업에서 확인했다. 기출 지문이나 선택지를 복제하지 않고 판단 구조를 참고했다.

각 문항은 정답 하나와 다섯 선택지별 근거를 대조했다. 기출과 같은 정답률·변별도·난도가 통계적으로 검증된 것은 아니다. 기출은 난도 수치를 복제한 대상이 아니라 독해 과정과 선택지 구성의 참고 자료다. 이 제작 설명과 대조 메타데이터는 풀이 화면에 표시하지 않는다.

## 구현과 보존

- 추가: `korean-flower.html`, `lessons/flower.js`, 이 검토 문서.
- 작품 메뉴에 ‘이육사 · 꽃’을 추가한다.
- 공통 렌더러의 국어 버튼 주소만 `lesson.page`를 우선 사용하도록 확장한다. 기존 봄 작품의 주소는 유지한다.
- 기존 〈길〉 페이지·실전 스크립트·봄 작품 데이터 및 수학 파일은 바이트 단위로 유지한다.
- 새 저장 키는 `study-poetry-flower-v1`; 콘텐츠 버전은 `flower-20260918-v1`이다. 다른 작품의 기록과 구분된다.
- 서비스 워커는 v13 → v14 및 새 HTML/데이터 캐시 등록만 변경한다. 요청 처리 로직은 수정하지 않는다.
- 소개·학습 우선순위·진행 설명·제작 및 난도 설명은 다시 추가하지 않는다. 출처는 접힌 영역에 유지한다.

## 기능 검증

- 새 데이터, 작품 메뉴, 공통 렌더러, 서비스 워커의 `node --check` 통과.
- 콘텐츠 구조·보존 검사와 Chromium 격리 DOM 검사 총 74개 통과: 19문항/12행, 기존 파일 유지, 전체 단계 진행, 오답 힌트와 재시도, 명시적 해설 열기, 미응답 제출 방지, 제출 전 정답 비공개, 답안 수정/복원, 전체 정답·오답 채점, 25개 선택지 해설, 제출 복원, 초기화 취소, 앞 단계 보존, 기존 저장 키 보존, 손상/차단 저장 처리, 중복 실행, 봄 작품 회귀 검사, 320/360/780/1100px 가로 넘침 없음, 미처리 오류 없음.
- 원본 스크립트에 location/localStorage/navigator 어댑터를 주입한 격리 DOM 검사다. 로컬 HTTP 탐색이 정상적으로 진행되지 않아 실제 네트워크 사이트의 E2E나 서비스 워커 수명 주기는 검증하지 못했다.
- 모바일 실전 화면을 렌더링해 직접 확인했다. 배포 성공 여부는 병합 후 GitHub Pages 작업 결과로 따로 확인한다.
