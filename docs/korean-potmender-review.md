## 수록·본문 확인 범위

- 2027 EBS 수능특강 문학 고전 시가 02, 48쪽. 남궁민 문학 06강의 [48쪽] 작품명과 한병훈 문학 10강의 적용 학습 ② 상세 목차를 직접 확인했다.
- 비교 작품 김삼현 〈내 영혼 술에 섞여〉도 두 공식 목차에 실려 있다. 교재 지면 판독이나 강의 시청은 하지 않았다.
- 본문은 공개 학습 자료의 고전 사설시조 전사를 사용한 학습용 표기이다. 특정 원전 영인본이나 비평적 정본을 확보한 것은 아니므로 원전의 옛 철자·교재 지면과의 완전한 일치를 보증하지 않는다.
- 주 본문 전사는 ‘공부어디까지해봤니’의 2026-05-11 글에서 작품으로 따로 제시된 세 줄이다. 해당 글의 문항·주석·현대어 해설을 복제하지 않았다. 문항·보기·힌트·해설은 자체 작성했다.
- 김세곤의 2006-12-25 공개 글에는 「창 밧끠 감아솟 막키라는 장사」가 인용되어 있으나 중장의 열거와 어휘가 다르다. 동일한 본문이 별도로 검증된 것처럼 간주하지 않고 이본으로 구별했다. 이본의 표현을 새 학습 본문에 섞거나 해당 글의 주인공에게 이 시조의 작자를 귀속하지 않았다.
- 사설시조 한 수의 초장·중장·종장을 세 줄로 표시한다. 세 연 또는 세 수가 아니다.
- 비교 본문은 기존 `lessons/soulwine.js`의 본문과 정확히 같다. 두 작품을 EBS에서 함께 다룬다는 사실과 이번 창작 문항이 EBS 문항이라는 주장은 구별한다.

## 해석의 경계

- 장사는 가마솥을 때우는 사람이며 임이나 역사 속 장수가 아니다. 실제 가마솥 수선 완료 장면은 없다.
- 중장의 말은 장사의 응답이다. 역사 인물은 사례이고, 「우스워라」의 평가 대상은 이별의 구멍을 때우라는 요청이다.
- 위엄·재주·힘의 열거는 이별을 막을 수 없다는 답의 근거이다. 역사 인물들이 동일한 수선 기술을 실제로 시험했다는 사건, 능력 순위, 역사적 시간 순서를 보태지 않는다.
- 「막았다는 말 못 들었고」를 직접 목격으로 바꾸지 않는다. 시에 든 사례의 기능을 설명하는 것이며 역사 인물들의 실제 연애사를 검증한 문항이 아니다.
- 장사의 말은 화자의 전망이 달라지는 계기이지 임과 헤어진 사건의 원인이 아니다.
- 「같을진대」의 조건적 적용과 「긴 이별」의 탄식은 슬픔의 해소나 재회의 불가능성이 객관적으로 증명된 사건과 다르다.
- 비교 작품에서 찾는 범위는 임의 몸속, 없애려는 대상은 임의 변심이다. 화자의 사랑이나 임의 감정 전체를 없애려는 것으로 바꾸지 않는다.

## 기출 대조와 문항

실제 2026학년도 수능 국어 짝수형 31~34번의 지문·보기·선택지와 인쇄 11~12쪽 이미지를 대조했다. 공식 문항을 복제하지 않고 독해 판단 구조를 참고했다. 수험생 정답률·변별도·풀이 시간은 수집하지 않았으므로 동일한 실측 난도를 주장하지 않는다.
