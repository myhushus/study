# 조식 〈두류산 양단수를〉 제작·검토 기록

확인일: 2026-10-02. 기준 커밋: `bde43712f59a84d4cac08ac223b14e7094f7a469`.

## 수록·원문 확인 범위

- 2027 EBS 수능특강 문학 고전 시가 04, 53쪽 수록작이다. EBSi 남궁민 문학 06강 상세 목차의 `[53쪽] 조식_두류산 양단수를~`를 확인했다. 한병훈 문학 11강의 `[53-54쪽] 적용 학습 ④`와 작품명도 확인했다.
- 비교 작품 김창협 〈산민〉의 244쪽 수록도 남궁민 06강의 공식 목차에서 확인했다. 교재 지면 판독이나 강의 시청을 했다는 뜻은 아니다.
- 원작은 위키문헌 가곡원류 계열 전사(표시 판번호 431648)와 저작권 만료 표시를 대조했다. 원전 영인본의 직접 판독은 아니다. 현대 번역·주석·문제·해설은 복제하지 않았다.
- 원작 한 수의 세 장을 세 줄로 표시했다. `stanzaLabel: sijo`를 사용하며, 세 연으로 분류하지 않는다. 한자·옛 철자·띄어쓰기를 학습용으로 정리했으므로 EBS 교재의 표기와 다를 수 있다.
- 주요 정리: `頭流山→두류산`, `兩端水→양단수`, `녜 듯고→예 듣고`, `桃花→도화`, `山影 좃ᄎᆞ→산영조차`, `ᄌᆞᆷ겨셰라→잠겨세라`, `兒㝆야→아이야`, `武陵→무릉`, `어드메오→어디메오`, `ᄒᆞ노라→하노라`.
- 비교 본문은 기준 커밋의 `lessons/sanmin.js`에 있는 자체 학습용 번역과 정확히 일치한다. 교재 번역과의 일치를 주장하지 않는다. 두 작품의 조합과 문제는 자체 구성이다.

## 해석·출제 범위

- `예 듣고 이제 보니`는 경험 방식의 변화다. 과거에 방문·거주했다거나 구체적으로 무엇이라고 들었는지는 확정하지 않는다.
- `도화`는 물에 떠 있고, `산영`은 물에 비친 산의 형상이다. 산 자체가 물에 잠기거나 화자가 물속으로 이동하는 사건으로 바꾸지 않는다.
- `조차`는 꽃이 떠 있는 경관에 산의 형상까지 더한다. 이 말만으로 부정적인 정서를 판정하지 않는다.
- `무릉`은 눈앞의 자연에 이상향의 이미지를 겹쳐 놓는 데 쓰인다. `옌가`는 현재 보는 이곳을 가리킨다. 실제로 다른 세계에 도착했다는 사건이 아니다.
- `아이야`로 상대에게 말을 건네지만 상대의 응답은 없다. `나는 옌가 하노라`는 화자 자신의 판단이다.
- 화자의 경관 예찬이 그 지역 모든 주민의 이상적인 생활 조건을 입증하지는 않는다.
- 〈산민〉에서는 직접 관찰과 여인의 전언, 이웃 없음과 독신 여부, 평지를 지향하는 마음과 과거 거주 경험, 산골에 계속 사는 행동과 제약 없는 선호를 구별한다.
- 마지막 문답은 산중 거주 이유를 보완한다. 산중의 어려움을 취소하거나 인물의 현실을 실제로 해결하는 결말로 읽지 않는다.

## 학습 구성

이해 유도 8 → 핵심 정리 → 일반 3 → 수능형 연습 3 → 실전 5, 총 19문항.

실전은 다섯 문항 전체 응답 후 채점하며 25개 선택지별 설명을 제공한다. 이해 단계는 오답 시 힌트를 먼저 제공하고 재시도 또는 명시적 해설 확인이 가능하다. 기존 공통 렌더러를 그대로 사용했다. 소개·진행·제작·난도에 대한 부가 문장은 학습 화면에 추가하지 않았다.
