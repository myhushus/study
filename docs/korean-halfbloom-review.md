# 안민영 〈고울사 저 꽃이여〉 제작·검토 기록

- 비교 작품 원천석 「눈 맞아 휘어진 대를」는 같은 강좌 [07강](https://www.ebsi.co.kr/ebs/lms/player/retrieveLmsPlayerHtml5.ebs?lecGbn=V500&lessonId=LS100030078062&sbjtId=S20250000854&sbjtapplyId=) 목차의 31:51에서 확인했다.
- 안민영의 저작권 만료 고전 본문은 [국어문학창고의 전사](https://seelotus.tistory.com/entry/고을사-저-꽃이여)와 [별도 전사](https://knock247127.tistory.com/721)의 원작 부분을 대조했다. 주변의 현대어 번역·해설을 복제하지 않았다. 특정 원전 영인본은 확인하지 못했다.
- 고을사→고울사, 여읜→여윈, 허여→하여, 나뷔→나비, 맞어 허노라→맞이하노라로 표기를 정리했다. 한 수의 세 장이며 세 연이 아니다. EBS 교재의 표기와 완전히 일치한다는 주장은 하지 않는다.
- 두 번째 전사는 표기 대조에만 사용했다. 그 페이지의 감상에는 반쯤 시듦과 반쯤 피어 있음이 혼재하므로 감상 문단은 해석 근거로 채택하지 않았다. 본문의 ‘여윈’은 시들어 가는 상태로 읽었다.
- 종장은 꽃을 의인화한 독해를 사용했다. 이 독해를 직접 묻는 문항에는 해당 관점을 명시했다. 특정 실제 인물·정확한 연령·꽃의 종류를 정답의 전제로 삼지 않았다.
- 비교 본문은 기존 `lessons/snowbamboo.js`의 `stanzas`를 빈 줄로 연결한 문자열과 정확히 일치한다. 작품 조합과 모든 새 문항·보기·힌트·해설은 자체 구성이다.

## 학습과 정답 검토

구성: 이해 유도 8 → 핵심 정리 → 일반 3 → 수능형 연습 3 → 실전 5, 총 19문항. 실전은 5문항 전체 제출 후 정답과 선택지별 근거 25개를 공개한다. 이해 오답에서는 힌트를 먼저 보여 준다.

- ‘반만 여윈’의 관찰은 ‘고울사’의 평가를 철회하지 않는다.
- ‘매양 그만하여 있어’는 현재 모습의 지속을 바라는 표현이지 과거 만개의 회복이나 지속의 실제 성취가 아니다.
- 나비는 향기를 좇는 존재이지 꽃이 시든 원인 또는 꽃을 다시 피우는 원인으로 제시되지 않는다.
- 꽃의 웃는 모습과 현재를 잃고 싶지 않은 애착은 양립한다.
- 비교 작품의 물리적 휨은 인정되지만 절개의 굴복은 반박된다. ‘굽을 절이면’이라는 가정을 실제 굴복 사건으로 바꾸지 않는다.
- ‘눈 속의 푸름’은 이미 유지되는 성질이다. 시련 이후에 새로 얻는 가치나 눈이 사라진 뒤의 회복으로 보지 않는다.

정답(1부터 시작): 이해 2·3·1·2·3·1·2·3 / 일반 4·2·1 / 수능형 3·5·2 / 실전 2·4·1·5·3.

## 보존과 변경 범위

게시 변경은 `korean-halfbloom.html`, `lessons/halfbloom.js`, `poetry-nav.js`, `service-worker.js`, 본 문서의 5개 파일이다. 기존 30작품·수학의 본문과 문항, 공유 렌더러·CSS는 변경하지 않는다. 메뉴는 현지화 키와 링크를 하나씩 추가하고, 서비스 워커는 v47→v48 및 새 HTML·데이터의 CORE 항목 두 개만 추가한다. 기존 요청 처리 코드는 유지한다.

새 저장 키는 `study-poetry-halfbloom-v1`, 콘텐츠 버전은 `halfbloom-20261004-v1`이다. 다른 작품과 수학의 저장 키를 삭제하거나 덮어쓰지 않는다. 소개·진행·제작·난도의 부가 문장은 풀이 화면에 추가하지 않는다.

## 검사 결과와 한계

- JavaScript 문법 검사 3개 통과. 콘텐츠·보존·Chromium DOM 검사 463개 세부 단언 통과. 이 수에는 이전 Pages 산출물 중 변경 대상 외 191개 파일 바이트 보존이 포함되며, 독립 사용자 시나리오 463개라는 뜻은 아니다.
- 최신 Pages 산출물이 만료되어 29작품 시점의 기존 첨부 산출물을 재사용했다. 현재 메뉴·서비스 워커를 복원해 GitHub의 현재 blob SHA와 일치함을 확인했다. 공유 렌더러의 SHA도 현재 저장소와 일치한다.
- 새 작품 19문항의 전 단계, 이해 오답 힌트·재시도·명시적 해설, 미응답 차단, 제출 전 답 비공개, 답안 수정·직렬화 복원, 5/5·0/5 채점, 25개 선택지별 근거, 제출 후 답안 고정과 결과 복원을 검사했다.

- 기존 공통 렌더러 28작품의 로드와 실전 만점 채점 회귀 검사를 통과했다. 최신 추가작 ‘꾀꼴꾀꼴 우는 소리에’는 로컬 산출물에 없으므로 조작 검사를 수행하지 않았다. 해당 파일은 현재 Git 트리를 기반으로 보존한다. 독립 렌더러 ‘길’과 수학의 직접 조작 검사도 수행하지 않았다.
- 320/360/780/1100px 초기 화면 및 실전 5문항 채점 전·후 가로 넘침이 없었다. 320px에서 본문·선택지·보기·참고 글자 200% 확대 검사도 통과했다. 360px 학습 화면과 실전 4번 스크린샷을 열어 확인했다. 미처리 JavaScript 오류는 없었다.
- localhost HTTP 탐색이 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단되어 `set_content`와 location/localStorage/navigator 테스트 대역을 사용한 격리 DOM 검사다. 기록 복원은 메모리 저장 대역의 직렬화·재주입 검사이지 실제 브라우저 영속 저장소 검증이 아니다. 실제 배포 도메인의 전체 조작과 서비스 워커 네트워크 수명 주기도 검증하지 않았다.
- 테스트 코드·대역·검토 JSON·스크린샷은 게시하지 않는다. 업로드 후에는 검사한 로컬 파일과 Git blob SHA를 대조한다.
