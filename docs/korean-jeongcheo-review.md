## 학습과 해석 범위

총 19문항: 이해 유도 8 → 핵심 정리 → 일반 3 → 수능형 연습 3 → 실전 5.

이해 단계는 관찰하는 쪽과 대상 → 물의 상태와 공통 바탕 → 의복의 예 → 때에 따른 일 → 도리와 마음 → 예와 주장 연결 → 조건적 청자 지향 → 말함과 침묵의 관계 순서다. 오답은 먼저 힌트를 제공하고 재시도 또는 명시적인 해설 확인이 가능하다.

- 물과 얼음, 털옷과 베옷은 차이를 없애는 실제 변화 과정이 아니라 차이 속 공통점을 밝히는 병렬적 예다.
- 상황에 맞춘 대응이 달라질 수 있다는 주장과, 모든 처신이 자동으로 도리에 맞는다는 주장은 구별한다.
- 청자의 이해를 조건으로 말한 것을 청자가 실제로 동의하거나 입장을 바꾸었다는 사건으로 읽지 않는다.
- 말함과 침묵을 각각 어느 한 인물에게 고정하여 배분하지 않는다.
- 두 작품을 단순히 ‘원칙을 버리는 사람’과 ‘상황을 고려하지 않는 사람’으로 나누지 않는다. 공통적으로 도리를 중시하되 차이의 이해와 원칙 이탈의 경계라는 강조점이 다름을 살핀다.
