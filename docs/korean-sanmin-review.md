## 본문과 번역

저작권 보호기간이 지난 한문 원작 16구 전체를 별도로 한국어로 옮겼습니다. 『농암집』 권1의 위키문헌 전사 본문과 표시 판번호 2407552를 대조했습니다. 원전 영인본 판독은 아니며, EBS와 외부 자료의 현대어 번역·주석·문제·해설을 복제하지 않았습니다.

> 下馬問人居 / 婦女出門看 / 坐客茅屋下 / 爲客具飯餐
>
> 丈夫亦何在 / 扶犁朝上山 / 山田苦難耕 / 日晩猶未還
>
> 四顧絶無隣 / 雞犬依層巒 / 中林多猛虎 / 采藿不盈盤
>
> 哀此獨何好 / 崎嶇山谷間 / 樂哉彼平土 / 欲往畏縣官

넷째 구는 일부 자료의 爲我 대신 대조 전사의 爲客을 따릅니다. 藿은 식용 콩잎, 盤은 소반으로 옮겼습니다. 네 읽기 구간은 네 구씩 묶은 학습용 분절이며 원작의 네 연을 뜻하지 않습니다. 따옴표는 한국어 번역에서 질문·응답의 주체를 드러내기 위해 붙였습니다. 교재의 한국어 표현 및 발췌 범위와 일치한다고 주장하지 않습니다.

## 해석의 경계와 구성

- 이해 유도 8 → 핵심 정리 8항목 → 일반 3 → 수능형 연습 3 → 실전 5, 총 19문항입니다.
- 남편의 산밭 노동은 여인의 말로 전해집니다. 나그네가 산밭에서 남편을 직접 보거나 남편이 귀가하여 말하는 장면을 만들어 내지 않습니다.
- 접대 행위와 생활의 풍족함은 별개입니다. 음식 제공을 곧바로 강요·징수·수탈로 해석하지 않습니다.
- 범의 위협과 콩잎을 충분히 얻지 못하는 어려움을 연결하되, 이웃의 감시나 짐승에 의한 수확물 약탈 등 제시되지 않은 사건을 덧붙이지 않습니다.
- 평지에 대한 긍정과 그곳에 가고 싶은 바람은 실제 이주 또는 과거 거주 경험과 다릅니다.
- 결말의 관리에 대한 두려움은 열악한 산골에 머무는 사회적 이유를 드러냅니다. 〈산민〉 자체에 구체적인 세금 징수 장면이 나오지는 않는다는 점을 〈농부를 대신하여 읊다〉와 구별합니다.
- 결말은 앞의 고통을 부정하거나 해결하지 않습니다. 나그네의 시정 요구나 관리의 응답을 후속 사건으로 만들어 내지 않습니다.
- 소개·진행·제작·난도에 관한 부가 문장을 학습 화면에 추가하지 않았습니다. 판본 및 확인 범위는 접힌 출처에 둡니다.
