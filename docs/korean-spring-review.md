## 학습 구성

이해 유도 8문항 → 핵심 정리 → 일반 3문항 → 수능형 연습 3문항 → 기출 대조 실전 5문항.

이해 단계는 오답 때 정답을 즉시 밝히지 않고 재독 힌트를 제공한다. 재시도하거나 명시적으로 해설을 확인한 뒤 진행할 수 있다. 완료 표시는 학습·해설 확인을 뜻하며 모두 맞혔다는 뜻이 아니다. 실전은 제출 전 답안 수정이 가능하고 전체 제출 후에만 채점·25개 선택지 근거·문항별 기출 대조 기록을 표시한다.

## 기출 대조

이번 작업에서 아래 EBSi 제공 실제 수능 문제지의 8~9쪽 본문과 페이지 이미지를 확인했다. 문항·선택지를 복제하지 않고 판단 구조만 참고했다.

|---|---|---|

| 2 | 2025학년도 24번 | 부름말과 술어를 따라 심리·행위의 주체와 대상을 확인한다. |
| 3 | 2025학년도 25번 | 표현 방식의 확인이 맞아도 그 효과에 붙인 해석을 별도로 검토한다. |
| 4 | 2025학년도 22번 | 한 작품의 특징을 다른 작품까지 확대하지 않고 공통 관계를 찾는다. |
| 5 | 2026학년도 23번 | 보기의 관점을 작품별로 적용하고, 한 층위의 공통점을 다른 층위의 동일성으로 확대하지 않는다. |

정답은 각 문항에 하나로 설정했다. 오답 근거는 단순한 정서 반대가 아니라 지시 대상 변경, 소망의 실행화, 인식 변화의 사건화, 일부 공통점의 과잉 일반화 등에 두었다. 실전 3번은 의인화라는 정확한 설명 뒤에 의문이 해소되었다는 부당한 효과를 붙인 선택지를 판별하게 한다.

수험생 표본에 의한 정답률·문항 변별도 검증은 없다. 학습 우선순위는 학습 목적을 표시하며 실제 출제 확률이나 동일 난도를 보증하지 않는다.

## 구현과 보존

- 추가: `korean-spring.html`, `lessons/spring.js`, `poetry-lesson.js`, `poetry-lesson.css`, `poetry-nav.js`.
- `korean.html`에는 작품 전환과 기존 실전 스크립트의 명시적 로드 태그만 추가했다. 기존 본문·문항·학습 로직은 유지한다.
- 기존 `korean-advanced.js` 및 모든 수학 파일은 변경하지 않는다.
- 새 키 `study-poetry-spring-v1`로 기록을 분리한다. 콘텐츠 버전 불일치·손상·범위 밖 답안을 검증한다.
- 새 시 추가 시에는 별도 lesson 데이터와 HTML 진입점을 만들고 작품 목록·오프라인 캐시에 추가한다. 화면 문구는 번역 사전, 교육 내용은 lesson 데이터로 분리했다.
- 서비스 워커의 기존 요청 처리 코드는 그대로 두고 캐시를 v12로 올려 새 정적 파일을 등록한다.

## 기능 검증

- 신규 JS 3개 및 서비스 워커의 `node --check` 통과.
- Chromium 격리 DOM에서 47개 점검 통과: 전체 학습 흐름, 오답 힌트/재시도, 제출 전 비공개, 답안 변경·복원, 미응답 제출 방지, 정답·오답 채점, 25개 해설·5개 대조 기록, 초기화 취소, 실전만 초기화, 기존 저장 키 보존, 손상된 기록, 저장 불가, 중복 실행, 기존 〈길〉 실전 로드, 320/360/780/1100px 가로 넘침 없음 등.
- 원본 스크립트를 수정하지 않고 location/localStorage/navigator/history 어댑터를 함수 인수로 주입한 격리 DOM 검사다. 실행 환경에서 네트워크 탐색(로컬 서버 포함)이 차단되어 실제 배포 사이트 E2E 검사는 수행하지 못했다.
