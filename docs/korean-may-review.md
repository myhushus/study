## 해석 범위

1연의 부재와 기억, 2연의 새로 도착한 소식을 구분한다. ‘기억만이’라는 특정 대목의 한정을 작품 전체로 확대하지 않는다. 상대를 성별·친족·연인 관계로 특정하는 외부 정보에 정답을 의존시키지 않는다.

글자에서 황해로, 종선에서 순풍과 섬으로 이어지는 이미지는 상대를 찾아가고 싶은 마음의 전개로 읽는다. 현재형의 생생함을 실제 탑승·도착의 증거로 단정하지 않으며, ‘찾아 갈까나’를 방문의 포기로 바꾸지 않는다. 말줄임표만으로 상대의 편지를 그대로 인용했다고 확정하지 않는다.

‘가르치러 간’ 상대를 ‘페스탈로치’와 ‘선생님’으로 잇달아 호명한다. 두 호칭을 두 동행 인물로 나누지 않는다. 소식에 반가워하는 마음은 화자의 것이며 이를 발신자의 반응으로 옮기지 않는다.

반가움과 근심은 한 관계 안에서 함께 나타날 수 있다. 풍랑에 대한 염려를 확인된 조난으로, 밀려오는 듯한 소리를 화자가 보낸 답장의 전달로 바꾸지 않는다. 상상 속 접근과 물리적 거리의 소멸, 애정의 지속과 근심의 해소를 각각 구별한다.

## 학습 구성

이해 유도 8문항 → 핵심 정리 → 일반 3문항 → 수능형 연습 3문항 → 기출 대조 실전 5문항. 총 19문항.

이해 단계는 오답에 재독 힌트를 제공하고 재시도 또는 명시적인 해설 확인 후 진행한다. 실전은 전체 제출 전 답안 수정이 가능하며, 제출 후 정답과 25개 선택지별 판단 근거를 표시한다. 소개·진행·난도·제작 설명은 풀이 화면에 추가하지 않았다. 기출 대조 메타데이터는 데이터와 이 문서에만 보존한다.

## 검증

- 기존 봄·꽃·참회록·낙원 학습에서 실전 5/5 채점과 6개 작품 메뉴를 회귀 점검했다. 기존 〈길〉 파일은 변경하지 않았다.
- 실전의 320·360·780·1100px 가로 넘침이 없음을 확인하고 360px 최초 화면과 보기/선택지 화면 이미지를 검수했다. 미처리 자바스크립트 오류는 없었다.
- 원본 스크립트를 수정하지 않고 `location`, `localStorage`, `navigator` 어댑터를 주입한 Chromium DOM 검사다. 파일 URL 탐색은 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단되었다. 실제 배포 사이트 네트워크 E2E나 서비스 워커 수명 주기 검증은 아니다.
