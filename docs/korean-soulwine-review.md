## 해석의 경계

- 내·날은 화자, 임의 속과 구회간장은 임의 내면, 날 잊고 남 향한 마음은 임의 마음이다.
- 술은 영혼이 임의 내면에 접근하는 상상적 매개이다. 실제 음주·죽음 이후의 사건·임의 응답을 확정하지 않는다.
- 찾아다닐망정과 스로려 하노라는 수고를 감수해서라도 임의 변심을 없애려는 뜻이다. 목적의 구체성과 실제 성취는 구별한다.
- 종장에서 목적을 밝힌다고 해서 먼저 실제 탐색을 마쳤고 그 결과 변심을 처음 발견했다는 순서를 만들지 않는다.
- 다는 행위의 범위를 강조한다. 완료를 표시하지 않으며, 날 잊고 남 향한으로 특정된 마음을 모든 감정으로 확대하지 않는다.

## 검사 결과와 한계

최종 축약 JSON을 포함한 변경 JavaScript 세 파일의 `node --check`와 게시 데이터/검토 JSON의 정확한 의미적 일치 검사를 통과했다. 최종 파일로 콘텐츠·파일 보존·Chromium DOM 검사 548개 세부 단언을 다시 통과했다. 548개의 독립 사용자 시나리오를 뜻하지 않으며, 변경 대상 외 기존 Pages 산출물 179개 파일의 바이트 보존과 메뉴·캐시 대상 존재 확인이 포함된다.

- 19문항 전 단계, 이해 오답 힌트·재시도·명시적 해설, 미응답 제출 차단, 제출 전 정답 비공개, 답안 수정·직렬화 복원, 5/5 및 0/5 채점, 25개 선택지 해설 일치, 제출 후 답안 고정과 결과 복원을 확인했다.
- 재풀이·초기화의 취소/확인과 범위 분리, 다른 기록 키 보존, 손상 JSON·버전 불일치·범위 밖 답안·저장 불가 처리, 직접 실전 진입과 중복 초기화 방지를 확인했다.
- 기존 공통 렌더러 25작품의 로드·실전 만점 채점 회귀 검사를 통과했다. 독립 렌더러 〈길〉과 수학의 직접 조작은 수행하지 않았고 파일 보존으로 확인했다.
- 320/360/780/1100px 초기 화면 및 실전 5문항의 채점 전·후 가로 넘침이 없었다. 320px에서 읽기 본문·선택지 텍스트를 두 배로 키운 검사도 통과했다. 360px 초기 학습 화면과 실전 4번 이미지를 직접 열어 확인했다. 미처리 JavaScript 오류는 없었다.
- localhost HTTP 탐색이 `ERR_BLOCKED_BY_ADMINISTRATOR`로 거부되어 `set_content`와 location/localStorage/navigator 테스트 대역을 사용했다. 복원은 메모리 저장 대역의 직렬화·재주입 검사이며 실제 브라우저 영속 저장소 검증은 아니다. 배포 도메인 전체 조작과 서비스 워커 네트워크 수명 주기도 검증하지 않았다. 테스트 코드·대역·스크린샷은 게시하지 않는다.
