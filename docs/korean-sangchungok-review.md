# 정극인 〈상춘곡〉 제작·검토 기록

확인일: 2026-09-20. 제작·검사 기준 커밋: `30582b93ea4d0562a2548582159bea2526409a3d`.

## 원문·수록 확인

- [EBSi 공식 2027 수능완성 최서희 국어 11강](https://www.ebsi.co.kr/ebs/lms/player/retrieveLmsPlayerHtml5.ebs?lecGbn=V500&lessonId=LS100030083851&sbjtId=S20260000169&sbjtapplyId=)의 강의 세부 목차에서 실전 모의고사 1회 정극인 〈상춘곡〉 수록을 확인했다. 검색 도구가 반환한 공식 페이지의 상세 목차에는 06:48부터 작품과 20번, 145쪽이 표시된다. 해당 페이지 직접 열기는 오류였으며, EBS 교재 원본의 본문·문항·해설을 직접 읽거나 복제한 것은 아니다.
- 본문은 [위키문헌 고정 판본 383059](https://ko.wikisource.org/w/index.php?title=상춘곡&oldid=383059)의 원작 전사와 저작권 만료 표시를 대조했다. [한국민족문화대백과사전 작품 항목](https://encykorea.aks.ac.kr/Article/E0027375)에서 작품·작가 정보를 확인했다.
- 옛 철자·한자·일부 어휘를 학습용으로 정리했다. 예: 하건마는→많건마는, 호재로다→혼자로다, 긘 거인고→그곳인가, 재폈는 듯→펼쳤는 듯. 원문의 역사적 철자를 보존한 전사도, 전체 현대어 번역도, EBS 판본의 복제도 아니다. 판본 차이와 이용 출처를 학습 화면의 접힌 출처에 기록했다.
- 본문의 여덟 묶음은 학습용 분절이다. 원작이 여덟 연으로 구성되었다고 오해하지 않도록 ‘1구간’부터 ‘8구간’으로 표시한다. 작품의 흐름을 생략하지 않고 전체를 다룬다.
- 비교 작품은 현재 저장소의 윤선도 〈만흥〉 여섯 수를 그대로 사용했다. 실제 EBS가 두 작품을 한 지문으로 묶었다고 주장하지 않는다.

## 해석과 문항의 범위

산림 생활의 긍정, 봄의 감각적 풍경, 새와의 흥취 공유, 이웃을 향한 권유, 술과 꽃향기, 시냇가의 감상, 산 위의 넓은 조망, 소박한 삶의 만족을 연결한다.

‘오늘 하고/내일 하세’ 등 제안을 완료된 일정으로 바꾸지 않는다. 이웃에게 유람을 권하거나 어른·아이가 함께 언급되더라도, 이후 ‘혼자 앉아’ 잔을 씻는 행동의 주체까지 모든 이웃으로 확대하지 않는다.

도화를 계기로 무릉을 떠올리는 것은 눈앞의 공간을 이상적으로 느끼는 표현이다. 뒤에 보이는 마을과 들을 현실과 단절된 전설 속 세계로 확정하지 않는다. 공명·부귀를 의인화한 구절을 특정 인물이 화자를 박해하는 사건으로 바꾸지 않는다.

〈만흥〉과는 자연 생활의 만족이 공통되지만, 임금의 은혜를 말하는 대목을 〈상춘곡〉에도 똑같이 있다고 확대하지 않는다. 타인의 평가·자기 판단·물질적 조건·만족의 근거를 구별한다. 비교 시구는 현행 본문의 ‘그리던 님’, ‘그 모른 남들은’, ‘임금 은혜’ 등과 대조했다.

## 학습 구성

이해 유도 8문항 → 핵심 정리 → 일반 3문항 → 수능형 연습 3문항 → 실전 5문항. 총 19문항.

이해 단계는 오답 시 재독 힌트를 제공하고 재시도 또는 명시적인 해설 확인 후 진행한다. 실전은 다섯 답안을 모두 제출한 뒤 채점한다. 제출 전 답안 수정, 답안 복원, 제출 후 다섯 문항의 25개 선택지별 해설을 지원한다.

소개·제작·난도·학습 방식 설명은 풀이 화면에 추가하지 않았다. 기출 대조 메타데이터는 데이터와 이 문서에만 남긴다. 실제 수험생 표본의 정답률·변별도는 측정하지 않았으며, 기출과 같은 정답률·난도를 실증 검증했다고 주장하지 않는다.

## 구현·보존

- 신규: `korean-sangchungok.html`, `lessons/sangchungok.js`, 이 문서.

- `poetry-lesson.js`: `passage` 번역 키와 선택적인 구간 표시 분기만 추가했다. 기존 현대시는 ‘연’, 〈만흥〉은 ‘수’로 표시한다. 저장·채점·단계 로직은 변경하지 않았다.

- 기존 아홉 작품의 본문·문항, CSS 및 모든 수학 파일은 기준 커밋의 파일과 바이트 단위 동일하다.
