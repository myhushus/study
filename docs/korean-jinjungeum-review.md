# 이순신 〈진중음〉 및 EBS 비교 지문 정리

확인일: 2026-09-21. 작업 기준: `b014587156d40dd66a8b2cb02163394e149eb5b6`.

## 수록 범위와 본문

- [EBSi 2027 수능특강 남궁민 06강](https://www.ebsi.co.kr/ebs/lms/player/retrieveLmsPlayerHtml5.ebs?lecGbn=V500&lessonId=LS100030078323&sbjtId=S20250000856&sbjtapplyId=)의 01:16 목차가 `[46쪽] 이순신_진중음`을 명시한다. 이 공식 목차를 직접 열어 확인했다.
- 대상은 세 수 가운데 `水國秋風夜`로 시작하는 **제3수의 여덟 구**다. 널리 알려진 `天步西門遠`으로 시작하는 제1수로 대체하지 않는다. 수록 범위는 [모두의 국어](https://modukorean.co.kr/2027-수능특강-문학-원가-진중음-해설-및-변형문제/)와 [김은광 수능국어](https://ekkorean.com/learn/classic-poetry-01)의 수록 자료를 교차 확인했다. EBS 교재 지면이나 원전 영인본 자체를 판독한 것은 아니다.
- 한문은 `水國秋風夜 / 愀然獨坐危 / 太平復何日 / 大亂屬玆時 / 業是千人貶 / 名猶四海知 / 邊憂如可定 / 應賦去來辭`를 기준으로 한다. 외부 전사에 天/千, 優/憂 등이 섞인 경우가 있어 수록 자료의 千人·邊憂를 따른다. 이 선택이 원전 전체의 문헌학적 교정을 뜻하지는 않는다.
- 원작 한시는 저작권 만료 작품이다. **한국어 본문은 이번에 별도로 작성한 학습용 풀이**이며 EBS나 외부 자료의 현대어 번역, 문제, 해설을 복제하지 않았다. 危는 높은 곳으로 풀되 특정 건축물의 구조에 정답을 의존시키지 않는다. 네 묶음은 두 구씩 나눈 학습 구간이며 네 연이라는 의미가 아니다.
- 비교 작품은 기존 윤선도 〈만흥〉여섯 수다. [EBSi 2027 남궁민 05강](https://www.ebsi.co.kr/ebs/lms/player/retrieveLmsPlayerHtml5.ebs?lecGbn=V500&lessonId=LS100030078322&sbjtId=S20250000856&sbjtapplyId=)의 01:35 `[308쪽] 윤선도_만흥`을 다시 확인했다. EBS의 실제 작품 묶음을 재현한 것은 아니다.

## 해석·문항 검토

이해 유도 8 → 핵심 정리 → 일반 3 → 수능형 연습 3 → 실전 5, 총 19문항.

공적을 깎는 반응의 전달과 화자의 자기 평가는 다르다. 이름이 알려진 범위로 평가 내용이나 전쟁 종결을 추론하지 않는다. 특정 왕이나 신하를 비판 주체로 단정하지 않는다. 귀거래사는 삶의 방향을 불러오는 인유이며 그 작자가 현재 등장한 사건은 아니다. 다짐의 강도가 앞의 조건을 완료된 사실로 바꾸지는 않는다. 〈만흥〉의 현재 생활과 〈진중음〉의 조건부 장래를 구별한다.

실전 정답: ② ④ ③ ① ⑤. 각 문항은 다섯 선택지별 판단 근거를 갖는다. 미응답 차단 및 전체 제출 후 채점 방식은 기존 렌더러를 사용한다.

## EBS 외 비교 지문 제거

- `korean-advanced.js`의 〈산유화〉 전문과 그 작품을 전제로 한 기존 5문항을 2027 수특 현대시 04 수록 **이육사 〈꽃〉** 및 새 5문항으로 교체했다.
- [EBSi 한병훈 03강](https://www.ebsi.co.kr/ebs/lms/player/retrieveLmsPlayerHtml5.ebs?lecGbn=V500&lessonId=LS100030078574&sbjtId=S20250000855&sbjtapplyId=)의 `[90~92쪽] 적용④`와 `이육사, 꽃`을 확인했다. 비교 본문은 현재 `lessons/flower.js`의 세 연과 정확히 같다.
- 길의 새 실전 정답: ③ ④ ⑤ ② ①. 25개 선택지별 근거를 교체했다. 새 키 `study-korean-gil-advanced-exam-v4`, 콘텐츠 ID `gil-exam-20260921-ebs-v4`. 1~4단계 및 과거 v3 저장 키를 삭제하거나 덮어쓰지 않는다.
- 열한 작품의 비교 대상이 모두 기존 EBS 학습 작품 목록 안에 있음을 데이터 구조로 점검했다. 과거 검토 문서의 산유화 언급은 당시 작업의 역사적 기록이며 현재 풀이 화면에서 사용하지 않는다.
