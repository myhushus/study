## 제작 원칙과 자체 검토

이해 유도 단계의 쉬운 질문은 유지한다. 실전에서는 정서를 단순히 맞히는 선택지를 줄이고, 실제 시구를 제대로 관찰했더라도 주체·효과·인과를 잘못 연결하면 오답이 되도록 구성한다.

25개 선택지 모두에 작품 내부 근거 또는 보기의 조건을 연결한 해설을 작성했다. 문항의 ‘적절한 / 적절하지 않은’ 방향과 해설의 판정을 대조했다. 정답의 유일성은 제작자 자체 검토이며, 독립적인 문항 심사나 수험생 대상 통계 검증을 뜻하지 않는다.

〈산유화〉의 꽃이 홀로 있다는 것에서 버림받은 사건이나 새의 소외를 확정하지 않았다. 〈길〉에서도 교통편의 존재를 정착 문제의 해결책으로 바꾸거나, 길이 많다는 사실을 방황의 원인으로 단정하지 않았다. 특정한 작가 전기나 사전 암기 없이 제시된 작품과 보기로 판정하는 것을 목표로 했다.

문장 길이는 난도 지표로 사용하지 않았다. 선택지의 길이만으로 답을 알아내기 어렵도록 문항 내부 길이를 점검했다. 공백 포함 문자 수 범위는 1번 43~46자, 2번 47~54자, 3번 78~80자, 4번 85~98자, 5번 70~78자다.

## 난도에 관한 한계

기출과 대조한 것은 독해 과정과 선택지 구성이다. 실제 정답률, 변별도, 풀이 시간은 아직 측정하지 않았다. 작품 친숙도, 사전 해설 학습 여부, 지문 분량에 따라 체감 난도는 달라진다. 따라서 ‘수능과 동일 난도’, 특정 등급 보장, 예상 정답률을 표시하지 않는다.

## 구현과 검증

- 기존 수학 페이지 및 `korean.html`의 1~4단계는 수정하지 않는다.
- 저장 키는 `study-korean-gil-advanced-exam-v3`로 분리한다. 이전 버전의 답안을 새 문항에 적용하지 않고, 이전 키를 삭제하지 않는다.
- 제출 전 답안 수정과 문항 이동을 허용한다. 정답, 25개 선택지 해설, 문항별 기출 대조 기록은 전체 제출 후 화면에 표시한다.
- 정적 사이트이므로 이는 화면상의 공개 시점 제어다. 소스 코드에 포함된 답을 보안상 숨기는 시험 시스템은 아니다.
- 서비스 워커는 캐시 이름을 `study-pwa-v10`에서 `study-pwa-v11`로 바꾼 것 외에는 동일하다. 이전 Git blob SHA 대조로 확인했다.

### 수행 결과

두 JavaScript 파일의 `node --check` 통과. 문항 5개, 선택지와 해설 각 25개, 고유 ID, 정답 인덱스, 발문 방향과 해설 판정, 기출 출처 필드의 정적 검사를 통과했다. 서비스 워커의 국어 스크립트 주입, 중복 방지, 수학 분리, 비 HTML 응답 유지 검사도 통과했다.

Chromium에서 다음 15개 점검을 통과했다: 초기 화면과 제출 전 비공개, 미응답 제출 방지, 답안 수정·화면 재생성 시 복원, 참고 시구 표시, 전체 채점·25개 해설·5개 기출 기록, 제출 상태 복원, 이전 저장 키 유지, 초기화 확인과 버전 분리, 오답 처리, 중복 실행 방지, 손상 상태 복구, 저장 실패 처리, 수학 경로 제외, 320/360/1000px 가로 넘침 없음, 미처리 오류 없음. 360px 화면을 이미지로 확인했다.

브라우저 검사는 실제 배포 사이트 방문이 아니라, 변경하지 않은 모듈에 location/storage 테스트 어댑터를 주입한 격리 DOM 검사다. 실제 도메인 탐색이 실행 환경에서 차단되어 실사이트 종단 간 검사로 주장하지 않는다. 배포 성공 여부는 별도로 GitHub Pages 작업 결과에서 확인한다.
